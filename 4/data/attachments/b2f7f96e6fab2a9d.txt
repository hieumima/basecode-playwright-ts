[📱 MOBILE (ƯU TIÊN)] CLS quá cao: 0.109 (chuẩn: < 0.1)
      → Thủ phạm CLS:
          - <div class="content-text" id="noidung">
          - <div class="info-product mb-2">
          - <div class="info-product mb-2">
          - <div class="info-product mb-2">
          - <li class="breadcrumb-item active">

[Vấn đề]: Các phần tử (không phải ảnh có sẵn width/height rõ ràng) thay đổi kích thước đột ngột trong lúc tải trang.
[Thông số hiện tại]: Phần tử gây nhảy: <div class="content-text" id="noidung"> | <div class="info-product mb-2"> | <div class="info-product mb-2">.
[Chỉ thị hành động]: Nếu là font chữ, dùng size-adjust. Nếu là ảnh/iframe, bắt buộc khai báo width/height hoặc CSS aspect-ratio. Đối với ảnh lazy-load, phải có kích thước giữ chỗ.
[Code thay thế]:
/* Giải pháp 1: Giữ chỗ bằng aspect-ratio */
.cls-element {
  aspect-ratio: 4 / 3; /* Điền tỷ lệ đo được */
  width: 100%;
}

/* Giải pháp 2: Sửa nhảy font bằng size-adjust */
@font-face {
  font-family: 'Fallback Font';
  src: local('Arial');
  size-adjust: 90%; /* Điều chỉnh để khớp font chính */
}
